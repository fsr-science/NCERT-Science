
# Glossary — Permutations and Combinations (Chapter 6)

> Quick-lookup table of every term and formula introduced in this chapter.


| Term                                                             | Meaning                                                                                                                                                                         | Formula / Notation                                        |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **Fundamental Principle of Counting** (Multiplication Principle) | If one event can happen in*m* ways, and — after it happens — a second event can happen in *n* ways, then the two events together (in that order) can happen in *m × n* ways. | Event₁ × Event₂ × …                                  |
| **Generalised multiplication principle**                         | The rule extends to any finite chain of events, each with its own number of ways.                                                                                               | *m × n × p × …*                                       |
| **Factorial** (*n* factorial)                                    | The product of all positive integers from 1 up to*n*.                                                                                                                           | \( n! = 1 \times 2 \times 3 \times \dots \times n \)      |
| **0!**                                                           | Defined by convention (not derived) so factorial formulas stay valid at the boundary case*r = 0* or *r = n*.                                                                    | \( 0! = 1 \)                                              |
| **Recursive factorial identity**                                 | Lets you peel off the top factor of a factorial.                                                                                                                                | \( n! = n \times (n-1)! \)                                |
| **Permutation**                                                  | An arrangement, in a*definite order*, of some or all objects from a set. Order matters — swapping two objects gives a different permutation.                                   | —                                                        |
| **ⁿPᵣ**                                                        | Number of permutations of*n* distinct objects taken *r* at a time, **no repetition**.                                                                                           | \( {}^nP_r = \dfrac{n!}{(n-r)!},\ 0 \le r \le n \)        |
| **Permutations with repetition allowed**                         | Number of ways to fill*r* ordered places from *n* distinct objects when the same object can be reused in different places.                                                      | \( n^r \)                                                 |
| **Permutations of objects not all distinct**                     | Arrangements of*n* objects where one group of *p₁* objects is identical, another group of *p₂* is identical, and so on.                                                       | \( \dfrac{n!}{p_1!\,p_2!\,\dots\,p_k!} \)                 |
| **Combination**                                                  | A*selection* of some or all objects from a set, **order irrelevant**. Choosing {A, B} is the same combination as choosing {B, A}.                                               | —                                                        |
| **ⁿCᵣ**                                                        | Number of ways of choosing*r* objects out of *n* distinct objects, order not counted.                                                                                           | \( {}^nC_r = \dfrac{n!}{r!\,(n-r)!},\ 0 \le r \le n \)    |
| **Link between P and C**                                         | Every combination of*r* objects can be internally re-ordered in *r!* ways, each re-ordering being a distinct permutation.                                                       | \( {}^nP_r = {}^nC_r \times r! \)                         |
| **Complementary-selection identity**                             | Choosing*r* objects to keep is the same act as choosing the other *(n − r)* to leave out.                                                                                      | \( {}^nC_r = {}^nC_{\,n-r} \)                             |
| **Equal-combinations identity**                                  | If two combination counts on the same*n* are equal, their lower indices either match or add up to *n*.                                                                          | \( {}^nC_a = {}^nC_b \Rightarrow a=b \text{ or } a+b=n \) |
| **Pascal-type addition identity**                                | Relates combinations of*n* objects to combinations of *n + 1* objects.                                                                                                          | \( {}^nC_r + {}^nC_{r-1} = {}^{n+1}C_r \)                 |
| **Vacant-places method**                                         | The standard proof technique: picture*r* empty slots and count, slot by slot, how many objects could go in each.                                                                | —                                                        |
| **Distinct objects**                                             | Objects that are all different from each other (contrast with*identical/repeated* objects, e.g. the two O's in ROOT).                                                           | —                                                        |
| **Face cards**                                                   | In a standard deck: Jack, Queen, King of each suit — 12 cards total.                                                                                                           | —                                                        |
