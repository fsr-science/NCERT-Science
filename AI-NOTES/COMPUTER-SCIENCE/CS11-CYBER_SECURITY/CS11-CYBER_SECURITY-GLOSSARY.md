## Easily-confused pairs

| Pair | The distinguishing question |
| ---- | --------------------------- |
| **Virus / Worm** | Does it need a user to open it (virus), or spread by itself over a network (worm)? |
| **Worm / Trojan** | Does it copy itself (worm), or pretend to be useful software and not copy itself (Trojan)? |
| **Virus / Trojan** | Does it replicate (virus), or only disguise itself (Trojan)? |
| **Phishing / Pharming** | Are you lured by a message (phishing), or redirected to a fake site even though you typed the right address (pharming)? |
| **Spyware / Adware** | Is it mainly collecting information (spyware), or mainly showing unwanted advertisements (adware)? |
| **Malware / Virus** | Is it the whole category (malware), or one kind within it (virus)? |
| **First-party / Third-party cookie** | Does it store your own login and auto-fill data, or your history for advertising? |
| **Cookie / Super cookie** | Is it deleted when you clear it, or does it come back from another stored copy? |
| **IP address / HTTP referrer** | Does it identify your device and location, or the page you came from? |
| **IP address / User agent** | Does it identify where your device is, or what browser and operating system it runs? |
| **HTTP / HTTPS** | Is the data plain text, or encrypted by an SSL certificate? |
| **Cyber troll / Cyber bully** | Does the person provoke a community (troll), or target and intimidate someone (bully)? |
| **Cyber bullying / Cyber stalking** | Is it abuse and intimidation, or persistent harassment, monitoring and information-gathering? |
| **Confidentiality / Identity theft** | Is it about who may see data, or about someone using your data to pose as you? |
| **Identity theft / Identity verification** | Is it the crime (theft), or the check that a user matches a real person (verification)? |
| **Documentary / Non-documentary verification** | Are you checking physical documents, or an authoritative database? |
| **Private browsing / VPN** | Does the browser merely not store cookies, or does your traffic pass through a private route? |
| **DoS / DDoS** | Does the attack come from one source, or from many compromised computers at once? |
| **Digital footprint / Cookie** | Is it the whole trail of your online activity, or one small file stored by a site? |
| **Biometrics / Biometric authentication** | Is it the measurement of body traits, or the use of those traits to prove identity? |
| **Recycling / Reuse (e-waste)** | Is the material processed into something else, or is the device kept in use? The book says reuse is better |
| **Hacker (expert) / Hacker (criminal)** | Is the person exploring systems, or breaking into them illegally? |
