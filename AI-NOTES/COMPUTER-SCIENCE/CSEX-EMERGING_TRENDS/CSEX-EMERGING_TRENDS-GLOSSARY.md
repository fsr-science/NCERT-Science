# Computer Science | Chapter EX | EMERGING TRENDS | GLOSSARY

Fast, unambiguous lookup — one entry, one meaning, no worked examples or reasoning (see `NOTES.md` for those). Every entry ends with a `§` back to the NOTES section it's drawn from. Entries marked *(Board book only)* don't appear in the NCERT text at all. Where a term has a known confusable pair, the one distinguishing fact is folded into the entry itself, not just a standalone description.

| Term | Definition |
|---|---|
| **Accelerometer** | A sensor in mobile phones that detects the device's orientation (how it's tilted/held) — distinct from the gyroscope, which tracks rotation/twist rather than tilt. (§3.4.2) |
| **Artificial Intelligence (AI)** | Technology that simulates natural human intelligence in machines so they can learn, reason, plan, perceive, and process language. AI is the umbrella field; Machine Learning and Natural Language Processing are separate subfields under it, not stages of one another. (§3.2) |
| **Augmented Reality (AR)** | The superimposition of computer-generated perceptual information over the existing physical environment — it *overlays* a digital layer without replacing the real world. Unlike Virtual Reality (which replaces the world) or Mixed Reality (which lets you interact with the overlaid objects), AR is view-only. (§3.2.3b) |
| **Big Data** | A huge volume of data that cannot be stored or processed using traditional data-management tools, characterised by the 5 V's: Volume, Velocity, Variety, Veracity, and Value. (§3.3) |
| **Block** | A secured chunk of data or a valid transaction in a blockchain; it has a header (visible to every node) and private data (visible only to its owner). (§3.7) |
| **Blockchain** | A decentralised, shared database/ledger in which every participating node holds a full copy, updated only after all nodes authenticate a transaction — unlike a traditional centralised database, where one location holds the only copy. (§3.7) |
| **Cloud Computing** | Distributed data processing in which scalable information resources/capacities are delivered as a service over the internet, typically pay-per-use. Distinguish from Grid Computing: a cloud provider *rents* infrastructure to paying users, while grid nodes *volunteer* resources to jointly solve one problem, and nobody pays. (§3.5) |
| **Control Node** | In grid computing, the server (or group of servers) that administers the whole network and keeps account of the resource pool — distinct from a Provider, which contributes resources, and a User, which consumes them. (§3.6) |
| **CPU / Processor Grid** | A type of grid where processing is moved between machines as needed, or a large task is divided into sub-tasks distributed across nodes for parallel processing — distinct from a Data Grid, which distributes data rather than computation. (§3.6) |
| **Data Analytics** | The process of examining data sets to draw conclusions about the information they contain, using specialised systems/software. (§3.3.2) |
| **Data as a Service** *(Board book only)* | A cloud-hosting concept where data itself — rather than infrastructure, a platform, or finished software — is delivered as an on-demand service over the web. (§3.5) |
| **Data Grid** | A type of grid used to manage large, distributed data requiring multi-user access — distinct from a CPU/Processor Grid, which distributes computation rather than data. (§3.6) |
| **DaaS (Desktop as a Service)** *(Board book only)* | An improved SaaS-style business model (first appearing in the early 2000s) that involves using multiple services simultaneously to complete one piece of work. (§3.5.1) |
| **Drone** | An unmanned aircraft, remotely controlled or flying autonomously via software-controlled flight plans, onboard sensors, and GPS. It is an application of Robotics — not, despite first appearances, an example of Augmented Reality. (§3.2.4) |
| **Everything as a Service** *(Board book only)* | The broader cloud-hosting idea that almost any IT requirement — not just infrastructure, platform, software, or data — can be met via the web through cloud hosting. (§3.5) |
| **Expert System** | A system built through AI that displays intelligent behaviour — it can learn, demonstrate, explain, and advise its users. (§3.2) |
| **Globus Toolkit** | An open-source software toolkit used to build grids; provides security, resource management, data management, communication, and fault-detection features. (§3.6) |
| **Grid Computing** | A network of computers working together, under the same protocol, to perform a task too difficult for a single machine — acting like a virtual supercomputer. Unlike IaaS cloud computing, grid nodes voluntarily pool spare capacity to solve one shared problem; nobody rents or pays. (§3.6) |
| **Gyroscope** | A sensor that tracks the rotation or twist of a device — it complements, rather than duplicates, the accelerometer, which detects orientation/tilt rather than rotation. (§3.4.2) |
| **Humanoid** | A robot that resembles a human being, such as Sophia or Mitra. (§3.2.4) |
| **Hybrid Cloud** *(Board book only)* | A cloud deployment that combines Public and Private clouds, sharing data/applications between them. (§3.5) |
| **IaaS (Infrastructure as a Service)** | A cloud service that provides raw computing infrastructure — servers, virtual machines, storage, network components — as a service, aimed at network architects. Unlike Grid Computing, IaaS is a paid rental from one provider, not a voluntary pooling of many nodes. (§3.5.1) |
| **Immersive Experience** | A technology-driven experience that pulls a person into a new or augmented reality, engaging their senses — achieved through Virtual Reality, Augmented Reality, or Mixed Reality. (§3.2.3) |
| **Internet of Things (IoT)** | A network of inter-related computing devices, machines, objects, and people, each with a unique identifier (UID), able to transfer data over a network without human intervention. Distinct from the Web of Things (WoT), the specific idea of using the web itself — rather than one app per device — as IoT's common interface. (§3.4) |
| **Knowledge Base** | A store of information consisting of facts, assumptions, and rules that an AI system uses for decision-making. (§3.2) |
| **Machine Learning (ML)** | A subsystem/application of AI in which computers learn from data using statistical techniques, without being explicitly programmed. It sits beside — not inside — Natural Language Processing: both are independent subfields of AI, though NLP often borrows ML techniques. (§3.2.1) |
| **MeghRaj / GI Cloud** | The Government of India's own cloud computing initiative (https://cloud.gov.in). (§3.5) |
| **Middleware** | Software required to connect numerous grid nodes (in terms of data and CPU) and implement the distributed processor architecture. (§3.6) |
| **Mixed Reality (MR)** *(Board book only)* | An environment beyond AR, where a user can interact in real time with virtual objects placed within the real world. Unlike AR, which only overlays information for viewing, MR objects respond and react as if physically present. (§3.2.3c) |
| **Natural Language Processing (NLP)** | A subfield of AI that helps computers understand and process human (natural) language. It is not a trait of Deep Learning or contained inside Machine Learning — NLP and ML are both separate subfields of AI. (§3.2.2) |
| **PaaS (Platform as a Service)** | A cloud service that provides a ready platform/environment to develop, test, and deliver software applications, without managing the underlying infrastructure — aimed at application developers, one layer above IaaS. (§3.5.1) |
| **Private Cloud** *(Board book only)* | A cloud deployment whose resources are dedicated solely to one organisation — unlike a Public Cloud, which is shared across multiple tenants via a third-party portal. (§3.5) |
| **Provider** *(grid role)* | In grid computing, the computer that contributes its resources to the network's resource pool — distinct from the Control Node, which administers the pool, and the User, who consumes from it. (§3.6) |
| **Public Cloud** *(Board book only)* | A cloud service provided to multiple users/organisations ("tenants") through a common portal owned by a third-party provider — unlike a Private Cloud, dedicated to one organisation. (§3.5) |
| **Robot** | A programmable machine that automatically carries out one or more tasks with accuracy and precision. (§3.2.4) |
| **Robotics** | The interdisciplinary branch of technology concerned with the design, fabrication, operation, and application of robots. (§3.2.4) |
| **SaaS (Software as a Service)** | A cloud service providing on-demand access to finished, licensed application software, usually through a browser — aimed at end users, the topmost layer above IaaS and PaaS. (§3.5.1) |
| **Sensor** | A device that detects and responds to electrical/optical signals, converting a physical parameter into a signal that can be measured electrically. (§3.4.2) |
| **Smart City** | An urban area that uses electronic IoT sensors to collect and use data to manage assets, resources, and services efficiently. (§3.4.3) |
| **Smart Sensor** | A sensor that takes input from the physical environment, uses built-in computing resources to perform predefined functions upon detecting specific input, and processes the data before passing it on. (§3.4.2) |
| **Value** *(Big Data characteristic)* | The hidden patterns and business worth locked inside a big-data set — the payoff that justifies processing the other four V's. (§3.3.1) |
| **Variety** *(Big Data characteristic)* | The combination of structured, semi-structured, and unstructured data types found in a big-data set. (§3.3.1) |
| **Veracity** *(Big Data characteristic)* | How trustworthy/consistent a big-data set is — distinct from Value, which is about the data's worth rather than its reliability. (§3.3.1) |
| **Velocity** *(Big Data characteristic)* | The speed at which data is generated and stored — distinct from Volume, which measures size rather than speed. (§3.3.1) |
| **Virtual Reality (VR)** | A three-dimensional, computer-generated situation that simulates the real world, immersing the user inside it, typically via a VR headset. Unlike AR or MR, VR fully replaces the real environment rather than overlaying or blending with it. (§3.2.3a) |
| **Volume** *(Big Data characteristic)* | The sheer size of a big-data set — distinct from Velocity, which measures the speed of generation rather than the size. (§3.3.1) |
| **VPS (Visual Positioning System)** | An emerging trend that uses Augmented Reality and camera imagery — rather than satellite signal alone — to pinpoint location; complements GPS, especially indoors or where GPS signal is weak. (§3.4.2) |
| **Web of Things (WoT)** | Using web services as a single common interface to connect many different IoT devices, instead of needing one app per device — the interface layer on top of IoT's device network, not a separate network of its own. (§3.4.1) |
