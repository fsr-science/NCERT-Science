## Easily-confused pairs

| Pair | The distinguishing question |
| ---- | --------------------------- |
| **Data / Information** | Has it been organised to mean something yet? |
| **RAM / ROM** | Can you write to it? Does it survive power-off? |
| **Primary / Secondary memory** | Can the CPU reach it **directly**? |
| **Cache / RAM** | Which sits closer to the CPU? (Cache — and it is faster) |
| **Register / Cache** | Registers are *inside* the CPU chip and hold the operands in use; cache holds copies of RAM contents |
| **Buffer / Cache** | A buffer smooths a **speed mismatch** between two components; a cache keeps **copies of frequently used data** nearer the CPU |
| **Program / Software** | One program solves one problem; software is the set of programs. A program in execution is a process |
| **ASCII / ISCII / Unicode** | English only (7-bit), Indian scripts on top of ASCII (8-bit), or every script in the world (universal)? |
| **Destructive write / Non-destructive read** | Does the operation *overwrite* what was there, or merely copy it out? |
| **Von Neumann / Harvard architecture** | One shared memory for instructions and data, or two separate ones? |
| **Microprocessor / Microcontroller** | Is RAM and ROM already on the chip? |
| **Address bus / Data bus** | Is it carrying *which location*, or *the bits themselves*? |
| **Compiler / Interpreter** | Whole program at once, or one line at a time? Needed at run time? |
| **Assembler / Compiler** | Input is assembly language, or high-level language? |
| **OMR / OCR / MICR** | A shaded mark, a character shape, or magnetic ink? |
| **Impact / Non-impact printer** | Does the head physically strike the paper? |
| **System / Application software** | Does it operate the machine, or do a job for the user? |
| **Freeware / FOSS** | Free to use, or free to use **and modify the source of**? |
| **General purpose / Customised software** | Ready-made for everyone, or tailor-made for one organisation? |
| **Soft copy / Hard copy** | On a disk, or on paper? |
| **Track / Sector / Cylinder** | A ring, a piece of a ring, or the same ring across every platter? |
| **Structured / Semi-structured / Unstructured** | Fixed record format, tags but no fixed format, or neither? |
| **Time / Space multiplexing** | Shared in turns, or divided into parts? |
| **Computer / Calculator** | Does it store a program and make logical decisions, or only compute arithmetic? |
