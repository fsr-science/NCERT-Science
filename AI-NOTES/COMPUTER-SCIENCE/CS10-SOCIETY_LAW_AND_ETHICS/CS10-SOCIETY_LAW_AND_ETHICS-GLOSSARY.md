## Easily-confused pairs

| Pair | The distinguishing question |
| ---- | --------------------------- |
| **Active / Passive footprint** | Did the user *choose* to share it, or was it collected without their knowledge? |
| **Plagiarism / Copyright infringement** | Is the wrong *passing off as your own* (honesty) or *using protected work without permission* (law)? |
| **Copyright / Patent / Trademark** | Creative work, invention, or brand identifier? |
| **Patent / Copyright (filing)** | Must you apply? Patent — yes; copyright arises with the work |
| **Industrial property / Copyright** | Inventions and brands, or literary and artistic works? |
| **Permissive / Copyleft** | May a later user do anything, or must they keep the same freedoms? |
| **Proprietary / Open-source licence** | Does the owner keep all rights and closed source, or is source open to study and modify? |
| **Freeware / FOSS** | Free to use, or free to use **and** source open? |
| **Shareware / Freeware** | Free only for a trial, or free outright? |
| **DRM / System-based restriction** | Does the restriction travel with the data, or only sit on one system? |
| **White hat / Black hat** | Authorised and reported, or unauthorised and malicious? |
| **Hacker / Cracker** | Skilled expert (possibly ethical), or a malicious intruder? |
| **Phishing / Spoofing** | Fake page to harvest data, or the broader act of masquerading as someone else? |
| **Virus / Worm / Trojan** | Needs a host file; spreads by itself; or disguised and not self-replicating? |
| **Identity theft / Phishing** | Using stolen identity, or tricking someone into giving the data? |
| **Threat / Vulnerability / Risk** | The danger, the weakness, or the chance-and-impact? |
| **Section 43A / Section 72A** | Security practices and compensation, or punishment for disclosure? |
| **Ethics / Law** | What you *should* do, or what you *must* do? |
| **Open source / Open data** | Software whose code is open, or stored data open to all? |
| **Cybercrime / Ordinary crime** | Is a computer the target or the tool? |
